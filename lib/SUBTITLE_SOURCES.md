## 📊 Altyazı Formatları

### SRT (SubRip) ✅ ÖNERİLEN
```
00:00:00,000 --> 00:00:05,000
Türkçe altyazı metni

Avantajlar: Evrensel, tüm cihazlar destekler
Dosya uzantısı: .srt
Uyumluluk: 100% (tüm oynatıcılar)
```

### ASS (Advanced SubStation Alpha)
```
[Script Info]
Title: Turkish Subtitles
...
Avantajlar: Stil, renk, efekt desteği
Dosya uzantısı: .ass
Uyumluluk: VLC, MPC-HC, Modern Oynatıcılar
```

### SUB (MicroDVD)
```
{0}{100}Türkçe altyazı
Avantajlar: Klasik format
Dosya uzantısı: .sub
Uyumluluk: DVD, Eski oynatıcılar
```

### VTT (WebVTT)
```
WEBVTT

00:00:00.000 --> 00:00:05.000
Türkçe altyazı

Avantajlar: Web video standartı
Dosya uzantısı: .vtt
Uyumluluk: Web oynatıcılar, Mobil
```

## 🔄 LOVELL - Altyazı İntegrasyonu

### Anime Oynatıcıya Altyazı Ekleme
```javascript
// AnimeCix API'den Türkçe fansub altyazı al
const subtitles = await fetchAnimecixSubtitles({
  animeId: 1,
  episode: 1,
  language: 'tr'
});

// Oynatıcıya ekle
player.loadSubtitles(subtitles, {
  format: 'srt',
  language: 'tr',
  delay: 0
});
```

### Film Oynatıcıya Altyazı Ekleme
```javascript
// OpenSubtitles'dan Türkçe altyazı indir
const subs = await fetchOpensubtitlesSubtitles({
  imdbId: 'tt0111161',
  language: 'Turkish'
});

// Oynatıcıya ekle
player.loadSubtitles(subs, {
  format: 'srt',
  language: 'tr'
});
```
